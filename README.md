# Scratch Grade Checker

## Project Overview

A simple Scratch project that asks the user to enter a mark and determines whether the result is **pass** or **fail**.

## How It Works

1. The program asks the user to enter their mark.
2. It checks whether the mark is **50 or higher**.
3. If the mark is 50 or above, the grade is set to **pass**.
4. Otherwise, the grade is set to **fail**.
5. The program displays the result.

### Example

```text
Enter your mark: 75
your grade is: pass
```

```text
Enter your mark: 40
your grade is: fail
```
